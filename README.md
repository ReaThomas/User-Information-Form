# User-Information-Form
My project uses a monolithic Spring Boot backend with a layered structure. The REST controller handles HTTP requests, the repository layer accesses the database through Spring Data JPA and Hibernate, and the User entity represents the database table. The application runs on Spring Boot's embedded Tomcat server. The frontend is separately deployed and communicates with the backend through REST APIs. It is not a microservices architecture because the backend functionality is contained within a single deployable Spring Boot service.
